# 2026-09-30 bake-off: top 10 WordPress.org plugins + WordPress core

`bench/bakeoff.sh` (phpcs WordPress-Extra vs mago + mago-wordpress), mean of 3 runs after a warm-up.
Versions: mago 1.50.0 / PHP_CodeSniffer version 3.13.6 (stable) by Squiz and PHPCSStandards, PHP 8.4.24, this package at v1.0.1-27-g64200e0.

Release check for v1.1.0 (`main` after the WPCS parity sprint, PRs #2, #4, #8). Load average
rose from 7 to 25 during the run, so **the timings are not comparable** and the README keeps
the 2026-09-28 figures. Per-rule counts moved against 2026-09-29 only where the parity fixes predict:

- `posts-per-page`: `-1` and `nopaging` are no longer reported (WPCS does not).
- `slow-db-query`, `posts-per-page`: array-key assignments and query strings are now checked.
- `prepared-sql-placeholders`: the sniff's token walk (LIKE handling, unescaped literals, counts).
- `global-variables-override`: element writes to protected globals; `$post_id` (WordPress core
  1048 → 1294).
- `valid-hook-name`: one report per call over the joined literal parts.
- `enqueued-resource-parameters`, `cron-interval`, `capital-p-dangit`, `wp-i18n`: newly ported
  sniff checks; `wp-deprecated-classes` no longer reports `instanceof`.
