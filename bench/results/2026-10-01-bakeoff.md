# Bake-off 2026-10-01: top 10 WordPress.org plugins + WordPress core

`bench/bakeoff.sh` (phpcs WordPress-Extra vs mago + mago-wordpress), mean of 3 runs after a warm-up.
Versions: mago 1.51.0 / PHP_CodeSniffer version 3.13.6 (stable) by Squiz and PHPCSStandards, PHP 8.4.24, this package at v1.1.0-10-g97f3c45.

Release check for v1.2.0 (`main` after Sprints B–G, #15–#17, on Mago 1.51.0). From this run on the
bench times only the rules a consumer gets by default: `wordpress/parentheses-spacing` (off by
default) is left out. Load average 5–9 throughout (Time Machine, endpoint security), so timings are
close to but not as quiet as the 2026-09-28 run. Per-rule counts versus 2026-09-30: the eight `generic/*`
rules are new (their counts equal phpcs's). Only two other counts moved, both from Sprint E (#13):
`prepared-sql-placeholders` on WordPress core 3 → 2 (no `QuotedDynamicPlaceholderGeneration` after a
multi-line string, as in WPCS) and `file-name` on Google Site Kit 3477 → 3481 (Sprint E's `file-name` changes:
namespace-aware test classes and the new properties).
