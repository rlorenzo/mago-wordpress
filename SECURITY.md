# Security policy

## Supported versions

Security fixes go into the latest 1.x release only. Upgrade to the newest version before reporting.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/rlorenzo/mago-wordpress/security/advisories/new),
with the affected version, a minimal reproduction and what an attacker could do with it.

This is a development tool maintained in spare time, so responses are best effort. Confirmed issues
are fixed in a new release and disclosed in a GitHub security advisory.

Bugs in Mago itself go to [carthage-software/mago](https://github.com/carthage-software/mago/security),
and bugs in PHP to [php/php-src](https://github.com/php/php-src/security).
