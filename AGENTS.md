# AGENTS.md

Mago worker extension (PHP 8.1+) porting WPCS sniffs to `mago lint`. User docs: `README.md`, `docs/`.

## Commands
- `composer install` then `just check` (= CI: validate, format-check, presets-check, PHPUnit, mago lint+analyze, corpus, corpus smoke). Pre-commit hook runs it.
- Single pieces: `just test`, `just lint`, `just analyze`, `just format`, `just test-corpus`.
- One rule: `vendor/bin/mago --workspace tests/corpus lint --only wordpress/<rule> rules/<rule>`.

## Layout
- `src/WordPressExtension.php`: registers every rule.
- `src/Linter/Rules/*Rule.php`: one rule per class; call-based rules extend `Linter/CallRule`.
- `src/Internal/`: shared helpers (`Report`, `Calls`, `PhpcsTokens`, `SniffMap` = WPCS sniff → rule codes).
- `src/Internal/WordPress/{Lists,CoreClasses,Levels}.php`: GENERATED by `bin/generate-lists.php` from WPCS; don't hand-edit.
- `wordpress*.mago.toml`: presets; the `# BEGIN/END generated` blocks come from `php bin/generate-presets.php`.
- `tests/Unit/`: PHPUnit. `tests/corpus/rules/<code minus `wordpress/`>/`: corpus fixtures.

## Adding/changing a rule
1. Rule class (docblock says which sniff/codes are ported and what isn't) + register in `WordPressExtension`.
2. `SniffMap` entry; regenerate presets (`php bin/generate-presets.php`).
3. Code in `tests/corpus/expected-rules.txt`; fixture dir with `// @mago-expect lint:<code>` on the line before each expected report. Any unexpected report fails.
4. Row in `docs/rules.md`; drop it from `docs/wpcs-coverage.md` "not ported" if listed.
- Match WPCS behavior exactly (levels, positions, phpcs:ignore codes, phpcbf fixes); verify against WPCS's own tests.

## Style
- `declare(strict_types=1)`, `final` classes, `use function` imports, 4-space indent; format with `just format`.
- Commits: Conventional Commits, e.g. `feat(rules): port X as generic/y`, `fix(<rule>): ...`.
